Try it live ↓ See the example site
Step 1

The problem it solves

Small-business owners need to change their hours, specials, and menu prices — without learning code, and without being able to accidentally destroy the site's layout. Calling the web person for every tweak is slow and expensive.

SiteKeeper splits the site in two: the words the owner edits, and the design only the web person touches.

Step 2

Words here, design there

The entire editable content of the example site lives in one plain file, content.json — fetched live below, exactly as the site reads it. The layout, colors, and fonts live in index.html and never appear in the file the owner touches.

    Step 4
    
The real editor

    
The full editor (admin.html) is a private page with friendly form fields — business info, announcement, specials, menu sections and items, hours. It's behind a site password, and it talks straight to GitHub: no server, no monthly fee, nothing to maintain.
